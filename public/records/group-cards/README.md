# Record category card banners

Thematic PNGs for **Your Cabinet** group cards. Filenames are defined in
`src/lib/records/recordGroupIllustrations.ts` (`RECORD_GROUP_CARD_FILENAMES`).

Suggested canvas: ~400×230 landscape, paper-cut style. Cards crop with `object-cover`.
The card chrome keeps the image well transparent (page paper shows through); the
title block uses the normal `bg-card` + `shadow-e1` face.

## Shipped

- compliance, plans, legal, fire-safety, electrical, mechanical, water, insurance,
  contractors, warranties, om-manuals, misc, uncategorised
